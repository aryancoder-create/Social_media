# Social Media App 🚀

Instagram-style social media platform built using **React + Vite**.

## ✨ Features
- Instagram-style Stories
- Post Feed with likes & actions
- Responsive left navigation
- Sticky right sidebar
- Fully responsive layout (desktop & mobile)

## 🛠 Tech Stack
- React
- Vite
- SCSS
- JavaScript

## 📦 Setup & Run
```bash
npm install
npm run dev
